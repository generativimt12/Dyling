# 🎬 Dyling — Audio / Video Synchronization for Android

> An Android project exploring ways to correct audio/video timing when playback devices introduce a synchronization offset.

[![Android](https://img.shields.io/badge/Platform-Android-3DDC84?logo=android&logoColor=white)](https://developer.android.com/) [![Project](https://img.shields.io/badge/Type-Experimental-6E56CF)](https://github.com/generativimt12)

## 🎯 Goal

Dyling is focused on the practical problem of **audio arriving at a different time from video**, especially in playback setups where an external audio device introduces latency.

The repository contains the Android project and its build configuration. The implementation should be evaluated on real hardware before treating any synchronization approach as universally compatible.

## 🧪 Project status

This is an active development / experimentation repository. Build success and real-device synchronization are separate validation steps.
